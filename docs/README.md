# SoloMate — Project Documentation

Status: DRAFT — Pending Project Lead publication review

## Project Overview
SoloMate is a travel assistance application.

## Architecture
- Mobile: Flutter
- Administration and Service Provider portals: Angular
- Backend: ASP.NET Core .NET 8
- Database: SQL Server / Entity Framework Core 8

## Documentation Areas
- Project requirements
- Architecture and technical contracts
- API documentation
- Module integration
- Testing and verification
- Approved release information

## Publication Policy
Only reviewed and approved documentation may be published.

Internal source snapshots, database backups, secrets,
personal information, and raw test evidence must remain
outside the public documentation repository.

Historical reports must not be represented as final
integration acceptance.

The authoritative Release 08 schema evidence is tracked
as a separate integration dependency.
